# FinalCta specification

## Overview
- **Target file:** `src/components/fingerprint/final-cta.tsx`
- **Interaction model:** static link with hover feedback

## Structure and styles
- Desktop uses a horizontal split with a 51px dark-purple heading.
- Action uses a purple gradient, 12px radius, and `14px 24px` padding.

## States
- Hover brightens the button and translates it upward by 1px.

## Responsive
- At 600px the CTA stacks and centers; heading becomes 37px.
