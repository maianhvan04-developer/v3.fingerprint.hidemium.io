# Interaction patterns

- Buttons use direct state changes with no route transition.
- Expand/collapse controls preserve their parent card/module and update `aria-expanded`.
- CDI filters are a segmented group with a purple active state.
- Copy actions acknowledge success in-place; JSON download uses a generated Blob.
- Language is persisted locally and does not require an account.
- Hover communicates interactivity with brightness, border, and subtle glow.
- All content remains usable without hover; reduced-motion is respected.
